# College-Chat-application
CollegeChat is a real-time campus messaging app with direct messaging, group chats, AI assistant (Gemini), file sharing, typing indicators, and a full admin panel. Built with React, Vite, Supabase (Auth, Database, Realtime, Storage), Zustand, and TailwindCSS. Features a premium neon-purple dark theme with glassmorphism UI, fully responsive design.
